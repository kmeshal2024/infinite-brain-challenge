## Screenshots plan (8 slots available)

Recommend the following order — first 3 are shown in search results:

1. **Hero shot** — "9 BRAIN GAMES IN ONE" tagline over game grid
2. **Pattern Memory gameplay** — shows the 3-star system
3. **Color Match gameplay** — visually striking (new feature!)
4. **Math 24 gameplay** — highlights skill ceiling
5. **Word Memory gameplay** — shows recall screen
6. **Daily rewards screen** — conveys retention loop
7. **Achievements + leaderboard** — conveys long-term depth
8. **Player profile / XP level** — conveys progression

**Tips:**
- Add a bold headline to each screenshot (white text on dark bg)
- Use your brand gradient for headline backgrounds
- Phone resolution: 1080x1920 (9:16) or 1080x2340 (9:19.5)
- Tablet: 1600x2560 (optional but boosts installs on tablets)

## A/B test ideas (via Play Console Store Experiments)

1. **Icon test:** Current icon vs. one with a visible number/letter
2. **Short description test:** Benefit-first vs. feature-list style
3. **Screenshot #1 test:** Text-heavy hero vs. pure gameplay screenshot

Run each experiment for at least 14 days and a minimum 90% confidence before
committing.
